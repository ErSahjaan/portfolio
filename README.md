# Er, Md Sahjaan Portfolio

Run `npm ci`, then `npm start` and open `http://localhost:3000/portfolio`.

Run `npm run build` to create a production bundle. Configure the host to serve `index.html` for direct requests to `/portfolio`.

Open **Resume Builder** from the portfolio to edit the prefilled resume and download a selectable-text PDF or a UTF-8 text file. Resume edits stay in the current dialog and reload from the portfolio when it is reopened.
